Conductor 1.7.0: remove a song from every library for good.

## New
- An admin can remove a song for good, from Encore 1.19 ("Remove from library…" in a song's menu) or with
  `encore.removeSongs`. That deletes the song and every other copy of it in any library. Encore shows each file
  that would go and asks you to confirm. The song then leaves every playlist and play queue, and every app drops
  its download. A song Conductor downloaded is set aside so it isn't fetched again (bring it back on the requests
  page).

## Files
- Linux: `conductor-1.7.0-linux-x86_64.tar.gz` and `-aarch64`, and the packages: `conductor_1.7.0_amd64.deb` (and
  arm64), `conductor-1.7.0-1.x86_64.rpm` (and aarch64), `conductor-1.7.0-1-x86_64.pkg.tar.zst` (and aarch64).
- Windows: `conductor-1.7.0-windows-x86_64.zip`.
- `SHA256SUMS.txt`, and `docker pull ghcr.io/d-safro/conductor:1.7.0` (also `1.7` and `latest`).

Upgrading from any 1.x: replace the program, the package or the image.
