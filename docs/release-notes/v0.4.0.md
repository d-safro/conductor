A big step toward 1.0: easy to install with everything around it, safe to keep for years, fast with big libraries,
and closer to what every Subsonic app expects. (There was no 0.3.0 release: it's all here.)

## New
- **Docker image and ARM64.** `ghcr.io/d-safro/conductor` for x86-64 and ARM64 (Raspberry Pi, most NAS boxes), and
  a Linux ARM64 download beside x86-64 and Windows. Every one is tested before it's built.
- **Prelude sets up the whole music lab for you**, in one Docker folder started together. Each service is "set it up
  for me", "I have one already", or off, and its address and keys go into Conductor's settings by themselves:
  - the downloader (slskd), on your own connection or inside a VPN with a kill switch;
  - Lidarr (its key shared with Conductor, your music as its root folder);
  - AudioMuse-AI (with its own non-admin Conductor account to read the library);
  - Pitch ("What's playing?") and Metronome (Automix analysis), built on your computer;
  - only if you choose AI: Ollama and Interlude's voice.
- **Downloads are optional.** Without a downloader, songs you don't have aren't shown, so a plain library server
  shows only what plays.
- **Fast with big libraries.** Measured with 100,000 songs: first scan ~10 s, ~75 MB of memory. Apps that fetch the
  whole library (Symfonium and others) take ~10 s instead of 2½ minutes; stars, genres and searches are 5-100×
  quicker.
- **Works with web apps** like Feishin's web version, which couldn't connect before (the API now answers them, as
  Navidrome does).
- **Closer to Navidrome's answers**, compared call by call: OpenSubsonic's song and album fields always there, the
  index-based play queue (`getPlayQueueByIndex`), and more detail in folders, artists and scan status.
- **Backups.** Every day Conductor saves one private zip in `<data>/backups` and keeps the newest 7. It holds the
  database, its password key, your settings and playlist pictures. `conductor backup` makes one now;
  `conductor restore FILE` brings one back, moving what was there aside rather than deleting it.
- **Shares.** `createShare` and friends: a link to songs, albums or playlists that anyone can play without an
  account, on the same public address as Jam.
- **Users from any app.** `getUsers`, `createUser`, `updateUser`, `deleteUser`, `changePassword` and `getAvatar`.
  The last admin can't be removed by accident.
- **Prelude's "With Docker"** now uses the published image and reads the same `config.toml`.

## Fixes
The four issues left from the last review:
- **Podcasts:** only admins can add, remove or refresh shows. Feeds, episodes and covers come only from the
  internet, never your own network (`podcast_local = true` allows that).
- **Smart playlists:** a rule can no longer read someone else's private playlist.
- **Phone sign-in:** at most 5 codes can wait from one address.
- **Wrong passwords:** limited per user per address (30 every 15 minutes from apps, 10 on the admin page). A right
  password resets the count, so a device with an old password doesn't lock the others out.

Also: `getUser` reads the real user (it used to answer for any name).

## Files
- `conductor-0.4.0-linux-x86_64.tar.gz`, `conductor-0.4.0-linux-aarch64.tar.gz`: one static program each. Unpack,
  then `./conductor setup`. Needs `ffmpeg` to convert formats.
- `conductor-0.4.0-windows-x86_64.zip`: `conductor.exe` with `install.ps1` to install it as a Windows service.
- `SHA256SUMS.txt`, and the image: `docker pull ghcr.io/d-safro/conductor:0.4.0`.
