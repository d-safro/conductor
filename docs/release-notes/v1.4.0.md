Conductor 1.4: a live event when what you asked for changes, so apps show it at once.

## New
- **`requests` in the live updates** (`encore.events`): when a song you asked for is found, starts downloading, moves
  along (every 10%), arrives, isn't found, or is set aside, your apps hear it at once; an admin hears every change,
  Lidarr's albums too. Encore 1.16's "Getting your songs" uses it.

## Files
- Linux: `conductor-1.4.0-linux-x86_64.tar.gz` and `-aarch64`, and the packages: `conductor_1.4.0_amd64.deb` (and
  arm64), `conductor-1.4.0-1.x86_64.rpm` (and aarch64), `conductor-1.4.0-1-x86_64.pkg.tar.zst` (and aarch64).
- Windows: `conductor-1.4.0-windows-x86_64.zip`.
- `SHA256SUMS.txt`, and `docker pull ghcr.io/d-safro/conductor:1.4.0` (also `1.4` and `latest`).

Upgrading from any 1.x: replace the program, the package or the image.
