Conductor 1.0. From here on, the promises in [STABILITY.md](../STABILITY.md) hold: every later 1.x release opens your
data and settings as they are, a backup from any 1.x release restores on any later one, and the Subsonic API and
Conductor's own extensions keep every call and field (new ones may be added).

1.0 is 1.0.0-rc.1 with two fixes; everything new since 0.5 is in the
[rc.1 notes](https://github.com/d-safro/conductor/releases/tag/v1.0.0-rc.1): settings in Podium, "Made for you"
without AudioMuse-AI, Linux packages, cached and capped conversions, the API's recorded contract, and the security pass.

## Fixes since rc.1
- **The Arch package's version** left out "rc.1", so 1.0.0 would have looked like the same version to pacman and not
  replaced it. Arch packages now spell a prerelease the way pacman sorts it (1.0.0rc.1, before 1.0.0), and CI checks
  that each installed package's version sorts where it should on Debian, Fedora and Arch.
- **SHA256SUMS.txt** listed the .deb and .rpm files with a `~` that GitHub turns into `.` in file names, so
  `sha256sum -c` couldn't find them. The files are now named as they're published.
- With `RUST_LOG=conductor::api=debug`, every Subsonic error the server answers with is logged with the app's name,
  to see what an app trips over.

## Tried with
- **Apps:** Encore (Android and desktop), Tempus and Ultrasonic (Android: browsing, search, streaming with seeking,
  stars, ratings, scrobbles, lyrics, podcasts, radio, shares and bookmarks, with no errors), Feishin's web version.
  The others in the [roadmap](../ROADMAP.md) are still to be tried one by one.
- **Linux:** the release runs a real home server (Docker); the packages are installed and removed on Debian, Fedora
  and Arch by CI.
- **Windows:** the tests and an install as a service (with `install.ps1`, restart and removal) run on Windows in CI on
  every change, but this release hasn't been run on a real Windows PC yet; an issue on GitHub if it trips is welcome.

## Files
- Linux: `conductor-1.0.0-linux-x86_64.tar.gz` and `-aarch64`, and the packages: `conductor_1.0.0_amd64.deb` (and
  arm64), `conductor-1.0.0-1.x86_64.rpm` (and aarch64), `conductor-1.0.0-1-x86_64.pkg.tar.zst` (and aarch64). Then
  `conductor setup`.
- Windows: `conductor-1.0.0-windows-x86_64.zip` (`install.ps1` installs the service).
- `SHA256SUMS.txt`, and `docker pull ghcr.io/d-safro/conductor:1.0.0` (also `1.0` and `latest`).

Upgrading from 0.5 or rc.1: replace the program, the package or the image; there's nothing to run. Encore 1.12 brings
"Made for you" from the server and one-button desktop updates.
