A security update: please upgrade.

## Fixes
- **The SQLite built into Conductor had a vulnerability** (CVE-2026-119375, [RUSTSEC-2026-0459](https://rustsec.org/advisories/RUSTSEC-2026-0459)).
  It matters most when Conductor opens a database file someone hands it (moving from Navidrome). Conductor now uses the
  fixed SQLite (sqlx 0.9, libsqlite3-sys 0.40), and every place that builds SQL as it runs was read again: each puts
  only fixed text, numbers and `?` placeholders into it, with every value bound separately.
- Databases from every earlier release (0.1 to 0.5.0) open and upgrade as before; this is checked on each change.

## Also
- **The API's contract.** Every call's answer has its fields and types recorded ([docs/api/](../api/)), with a spec for
  each of Conductor's own extensions. The tests check every answer against it, and from 1.0 a field can be added but
  never dropped or changed. The list of extensions no longer names calls that don't exist (smart playlists and playlist
  pictures go through the Navidrome stand-in, as Encore uses them).
- Every change is now checked against the RustSec advisory database.
