The first step toward 1.0: easier to install, safe to keep for years, and complete enough for any Subsonic app.

## New
- **Docker image and ARM64.** `ghcr.io/d-safro/conductor` for x86-64 and ARM64 (Raspberry Pi, most NAS boxes), and
  a Linux ARM64 download beside x86-64 and Windows. Every one is tested before it's built.
- **Downloads are optional, and one container when you want them.**
  - Prelude's downloads step can set the downloader (slskd) up for you as one Docker container: you give it a
    Soulseek login and a folder.
  - The VPN step can put that same container inside a VPN, or leave it on your own connection.
  - Without a downloader, songs you don't have aren't shown, so a plain library server shows only what plays.
- **Backups.** Every day Conductor saves one private zip in `<data>/backups` and keeps the newest 7. It holds the
  database, its password key, your settings and playlist pictures. `conductor backup` makes one now;
  `conductor restore FILE` brings one back, moving what was there aside rather than deleting it.
- **Shares.** `createShare` and friends: a link to songs, albums or playlists that anyone can play without an
  account, on the same public address as Jam.
- **Users from any app.** `getUsers`, `createUser`, `updateUser`, `deleteUser`, `changePassword` and `getAvatar`.
  The last admin can't be removed by accident.
- **Prelude's "With Docker"** now uses the published image and reads the same `config.toml`.

## Fixes
The four issues left from the last review:
- **Podcasts:** only admins can add, remove or refresh shows. Feeds, episodes and covers come only from the
  internet, never your own network (`podcast_local = true` allows that).
- **Smart playlists:** a rule can no longer read someone else's private playlist.
- **Phone sign-in:** at most 5 codes can wait from one address.
- **Wrong passwords:** limited per user per address (30 every 15 minutes from apps, 10 on the admin page). A right
  password resets the count, so a device with an old password doesn't lock the others out.

Also: `getUser` reads the real user (it used to answer for any name).

## Files
- `conductor-0.3.0-linux-x86_64.tar.gz`, `conductor-0.3.0-linux-aarch64.tar.gz`: one static program each. Unpack,
  then `./conductor setup`. Needs `ffmpeg` to convert formats.
- `conductor-0.3.0-windows-x86_64.zip`: `conductor.exe` with `install.ps1` to install it as a Windows service.
- `SHA256SUMS.txt`, and the image: `docker pull ghcr.io/d-safro/conductor:0.3.0`.
